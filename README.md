<p align="center">
  Este projeto veio como necessidade aos Recursos Humanos uma forma de conseguir <b style="color:blue"> organizar </b> toda a papelada e reduzir em massa a quantidade de papel gasta pela empresa. Consiste por um sistema complexo de marcação de férias / faltas e ainda um histórico dos mesmos para um melhor controle das ausências que se dá no trabalho. Para além dessa informação ainda temos documentos como recibos de vencimento e documentos IRS que são de carácter obrigatório dar ao colaborador. Acrescentando extras, a aplicação ainda contém organização para refeitório (ementa semanal), sistema de feedback e apresentação de feed como também de parcerias associadas. 
</p>

## 2. FUNCIONALIDADES

<p align="justify">
  Como dito anteriormente, este software veio para melhorar a flexibilidade e a organização da empresa Patrícia Pilar, e, para isso, separei em categorias aquilo que a aplicação tem como função:
</p>

 - Marcação de Férias e Ausências
 - Histórico de marcações realizadas (Sucedidas, pendentes e recusadas)
 - Aprovações dos mesmos
 - Exibição de documentos (Recibos de vencimento e IRS)
 - Feed de Notícias / Eventos
 - Visualização de parcerias
 - Ementa do refeitória da firma
 - Sistema de Feedback
 - Modo de Suspensão (Token temporário)

## 4. BASE DE DADOS

A linguagem de consulta estruturada que usei foi o "SQL" com o ambiente integrado "Microsoft SQL Server Management Studio". Este projeto foi criado juntamente com uma base de dados a acessar dados da principal da empresa. Para fases de testes criei um script que adiciona 2 usuários que podem ser usados para testes.
